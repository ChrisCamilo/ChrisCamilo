## About

I build and maintain automation frameworks and grow test coverage across UI and API applications. Over the past few years I've worked with **Selenium**, **Robot Framework**, **Playwright**, and custom C# automation frameworks, integrating with tools like Jira/Xray, GitLab CI/CD, and AWS (CloudWatch, S3, DynamoDB, EC2). I also have experience leading development teams and mentoring other engineers.

🎓 Before moving into QA, I led React/React Native projects at Info Jr., mentoring new developers and running Scrum ceremonies (daily, grooming, retro, sprint review).

🤖 I'm actively exploring AI-assisted engineering, with certifications in Prompt Engineering, Model Context Protocol, and Claude subagents.

☁️ Hands-on with cloud-backed test infrastructure, from analyzing AWS CloudWatch logs to building GitLab CI/CD pipelines that trigger automated runs on EC2.

✝️ Christian, and I try to carry that into how I work and treat people.
