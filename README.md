## About

I design and own test automation frameworks in **C# / .NET** (Selenium, SpecFlow, NUnit, Page Object Model) and **Python** (Robot Framework), running in **GitLab CI/CD** on **AWS** and in **Jenkins** for UI automation.

🎯 I push test design beyond the happy path: boundary values, equivalence partitioning, decision tables and negative scenarios, with requirements traceability.

♻️ I build generic, readable automation that the whole team, not only QA, can understand and run.

🔍 Root cause analysis is my daily bread: CloudWatch logs, S3 files, DynamoDB records and remote EC2 instances.

🎓 Before QA, I was a React / React Native project director at Info Jr. (UNESP Junior Enterprise), so I bring a developer's perspective to quality.

🤖 Exploring AI-assisted engineering with Claude Code and GitHub Copilot, plus 18 AI courses from Anthropic, IBM and DeepLearning.AI.

✝️ Christian, and I try to carry that into how I work and treat people.
